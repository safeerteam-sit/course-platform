# منصة الكورسات

موقع عربي (RTL) لعرض وبيع الكورسات، مبني بـ **React 19 + TypeScript + Tailwind CSS v4 + Vite 8 + Lucide React**، مع **Supabase** للطلبات والإيصالات ولوحة التحكم.

## التشغيل

```bash
npm install
npm run dev        # تشغيل محلي
npm run build      # بناء نسخة الإنتاج في dist/
```

> إن ظهر خطأ توافق في الإصدارات أثناء `npm install`، شغّل:
> `npm i -D vite@latest @vitejs/plugin-react@latest @tailwindcss/vite@latest`

## الوضع التجريبي vs الحقيقي

- **بدون ملف `.env.local`**: الموقع يعمل في «وضع تجريبي»: الطلبات والإيصالات تُحفظ في متصفحك فقط، ولوحة التحكم مفتوحة بلا دخول. مفيد لتجربة الشكل والمسار.
- **مع ضبط Supabase**: الطلبات تُحفظ فعلياً، والإيصالات في مخزن خاص، ولوحة التحكم تتطلب تسجيل دخول الأدمن.

## ربط Supabase (مرة واحدة)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. افتح **SQL Editor ← New query**، والصق محتوى `supabase/schema.sql` كاملاً، ثم **Run**.
3. **Authentication ← Users ← Add user**: أضف بريدك وكلمة سر قوية.
4. في SQL Editor شغّل (مع بريدك) لتجعل الحساب أدمن:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'your-email@example.com';
   ```
5. **Authentication ← Providers ← Email**: عطّل «Allow new users to sign up» حتى لا يُنشئ أحد حساباً غيرك.
6. انسخ `.env.example` باسم `.env.local` وضع فيه `Project URL` و`anon public key` من **Project Settings ← API**.
7. على Cloudflare Pages أضف نفس المتغيّرين (`VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`) في Settings ← Environment variables.

> لا تضع مفتاح `service_role` في الموقع أبداً.

## مسار الشراء

السلة ← **إتمام الطلب** ← اختيار فودافون كاش أو إنستاباي ← تظهر بيانات التحويل والمبلغ بالجنيه مع زر نسخ ← يكتب العميل بياناته ويرفع صورة الإيصال ← يستلم **رمز طلب** (مثل `ORD-7K3F9Q`) ويظهر الطلب في لوحة التحكم بحالة «قيد المراجعة».

## لوحة التحكم

الرابط: `/#/admin` (وفي أسفل الموقع «دخول الإدارة»).
- عدّادات الطلبات والمبالغ (قيد المراجعة / مؤكَّد / مرفوض) وبحث بالرمز أو الاسم أو الهاتف.
- **مراجعة الإيصال**: صورة الإيصال بجانب المبلغ المطلوب، ثم **تأكيد الدفع** أو **رفض** (سبب الرفض مطلوب)، أو إعادة الطلب للمراجعة.
- زر **راسل العميل** يفتح واتساب برسالة جاهزة حسب الحالة.

## ما الذي تعدّله؟

| المطلوب | الملف |
|---|---|
| اسم المنصة، واتساب، بيانات المحاضر، **بيانات الدفع** | `src/config.ts` |
| الكورسات: العناوين، الأسعار، المناهج، الألوان | `src/data/courses.ts` |
| نصوص الصفحة الرئيسية | `src/data/content.ts` |
| ألوان الموقع وخطوطه | `src/index.css` (قسم `@theme`) |

### مهم قبل النشر
- **بيانات الدفع** في `config.ts` (`payment`) فارغة عمداً: ما دامت فارغة لن تظهر طريقة الدفع للعملاء. اكتب رقم المحفظة وعنوان إنستاباي الحقيقيين.
- صفحة «عن المحاضر»: استبدل النصوص التجريبية في `instructor` بقصتك، وأضف `achievements` بأرقامك الحقيقية فقط.
- رقم الواتساب `whatsappNumber` تجريبي: ضع رقمك بالصيغة الدولية بدون `+`.
- الأسعار والمدد والمناهج أمثلة: عدّلها. وأسعار تحويل العملات تقريبية (الدفع دائماً بالجنيه).
- قسم آراء المتدربين وأرقام المتدربين مخفية حتى تضيف بيانات حقيقية.

## ملاحظات أمان

- المبلغ والكورسات تُرسَل من المتصفح، لذلك **قارن دائماً المبلغ في الإيصال بالمبلغ الظاهر في لوحة التحكم** قبل التأكيد (هذه وظيفة المراجعة اليدوية).
- صور الإيصالات في مخزن خاص، ولا يراها إلا الأدمن عبر روابط مؤقتة (10 دقائق).
- إن ظهر سبام في الطلبات لاحقاً، أضف Cloudflare Turnstile على نموذج الطلب.

## الهيكل

```
src/
├── components/   Navbar, Hero, CourseCard, CartDrawer, CopyButton, ...
├── pages/        Home, Store, CourseDetails, Instructor, Checkout, Admin
├── context/      StoreContext (السلة، العملة)
├── data/         courses.ts, content.ts
├── lib/          orders.ts (الطلبات + Supabase)، supabase.ts، image.ts، api.ts، router.tsx
└── config.ts
supabase/schema.sql   جداول الطلبات والأدمن وسياسات الأمان ومخزن الإيصالات
```

الراوتر يعتمد على الـ hash (`#/courses`)، فيعمل على أي استضافة بدون إعدادات إضافية.
